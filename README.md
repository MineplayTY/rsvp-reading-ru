# RSVP Reader

Svelte-приложение для скоростного чтения методом **Rapid Serial Visual Presentation (RSVP)** с поддержкой PDF и EPUB.

**Демо:** https://rsvp.n0name.eu/

## Что такое RSVP?

**Rapid Serial Visual Presentation (RSVP)** — это техника скоростного чтения, при которой текст отображается **по одному слову за раз в фиксированной точке**.

Такой подход уменьшает необходимость перемещать взгляд между словами (саккады) и потенциально позволяет значительно увеличить скорость чтения.

Приложение использует подсветку **Optimal Recognition Point (ORP)** — оптимальной точки распознавания слова. Красная буква в каждом слове показывает место, на котором глазу естественнее всего сфокусироваться для быстрого распознавания слова.

Позиция ORP рассчитывается в зависимости от длины слова:

* **1–3 буквы** — 1-я буква
* **4–5 букв** — 2-я буква
* **6–9 букв** — 3-я буква
* **10 и более букв** — 4-я буква

## Возможности

* **Поддержка PDF и EPUB** — загрузка PDF-документов и EPUB-книг напрямую в приложение
* **Настройка скорости чтения** — от 50 до 1000 слов в минуту (WPM)
* **Подсветка ORP** — выделение красным цветом фокусной буквы каждого слова
* **Моноширинный шрифт** — фиксированная ширина символов помогает сохранять фокусную точку на одном месте
* **Режим фокусировки** — минимальный интерфейс во время чтения для уменьшения отвлекающих элементов
* **Эффект затухания** — плавные переходы между словами
* **Паузы на знаках препинания** — дополнительная пауза после окончания предложений
* **Периодические паузы** — автоматическая пауза через заданное количество слов для лучшего понимания текста
* **Отслеживание прогресса** — индикатор прогресса и оставшееся время чтения
* **Сохранение прогресса** — сохранение текущей сессии и возможность продолжить чтение позже
* **Переход к нужной позиции** — переход к определённому номеру слова или проценту текста
* **Кликабельный прогресс-бар** — возможность перейти к нужной позиции нажатием на прогресс-бар
* **Горячие клавиши** — полноценное управление с клавиатуры
* **Тёмная тема** — чёрный фон, удобный для длительного чтения

## Установка

```bash
# Клонирование репозитория
git clone https://github.com/yourusername/rsvp.git
cd rsvp

# Установка зависимостей
npm install

# Запуск сервера разработки
npm run dev
```

После запуска приложение будет доступно по адресу, который укажет Vite.

## Docker

Запустить приложение через Docker Compose:

```bash
cd docker
docker compose up -d
```

Приложение будет доступно по адресу:

```text
http://localhost:8080
```

Чтобы пересобрать контейнер после внесения изменений:

```bash
docker compose up -d --build
```

### Загрузка текста

#### Из файла

1. Нажмите на иконку документа в верхней части приложения.
2. Нажмите **«Загрузить PDF или EPUB»**.
3. Выберите PDF- или EPUB-файл.
4. Текст будет автоматически извлечён и загружен в приложение.

#### Ввод текста вручную

1. Нажмите на иконку документа в верхней части приложения.
2. Вставьте или напишите текст в текстовом поле.
3. Нажмите **«Загрузить текст»**.

## Управление

### Кнопки

* **Play** — начать чтение с начала или с текущей позиции
* **Pause** — поставить чтение на паузу и перейти в режим фокусировки
* **Resume** — продолжить чтение с текущей позиции
* **Stop** — остановить чтение и вернуться в начало
* **Restart** — остановить чтение и сразу начать заново

### Горячие клавиши

| Клавиша            | Действие                                                |
| ------------------ | ------------------------------------------------------- |
| `Space`            | Запуск / пауза / продолжение                            |
| `Escape`           | Выйти из режима фокусировки или закрыть диалоговое окно |
| `Arrow Up`         | Увеличить скорость на 25 WPM                            |
| `Arrow Down`       | Уменьшить скорость на 25 WPM                            |
| `Arrow Left`       | Вернуться на одно слово назад                           |
| `Arrow Right`      | Перейти на одно слово вперёд                            |
| `G`                | Открыть окно перехода к позиции                         |
| `Ctrl+S` / `Cmd+S` | Сохранить текущий прогресс                              |

## Сохранение и продолжение чтения

### Сохранение прогресса

Сохранить текущую сессию можно двумя способами:

* нажать на иконку сохранения (дискета) в верхней части приложения;
* нажать `Ctrl+S` в Windows/Linux или `Cmd+S` на macOS.

В браузерном хранилище сохраняются:

* текущая позиция;
* текст;
* настройки чтения.

### Продолжение чтения

При следующем открытии приложения, если существует сохранённая сессия, приложение предложит продолжить чтение.

Нажмите:

* **«Продолжить»** — чтобы продолжить с сохранённой позиции;
* **«Начать заново»** — чтобы начать новую сессию с текстом по умолчанию.

## Переход к определённой позиции

### Через окно перехода

1. Нажмите на иконку скобок в верхней части приложения или клавишу `G`.
2. Введите номер слова, например `150`, или процент, например `50%`.
3. Нажмите **«Перейти»** или клавишу `Enter`.

### Быстрый переход

Для быстрого перемещения можно использовать готовые кнопки:

* **Начало**
* **25%**
* **50%**
* **75%**

### Кликабельный прогресс-бар

Когда чтение не запущено, можно нажать в любом месте прогресс-бара и сразу перейти к соответствующей позиции текста.

При наведении курсора прогресс-бар увеличивается, чтобы по нему было удобнее нажимать.

## Настройки

Нажмите на иконку шестерёнки, чтобы открыть настройки.

Доступны следующие параметры:

* **Слов в минуту** — скорость чтения от 50 до 1000 WPM
* **Включить эффект затухания** — плавный переход между словами
* **Длительность затухания** — длительность эффекта от 50 до 300 мс
* **Пауза на знаках препинания** — дополнительная пауза после окончания предложений
* **Множитель паузы на знаках препинания** — увеличение продолжительности паузы от 1 до 4 раз
* **Пауза каждые N слов** — периодическая пауза через заданное количество слов; `0` отключает функцию
* **Длительность паузы** — продолжительность периодической паузы от 100 до 2000 мс

## API

### Утилиты (`src/lib/rsvp-utils.js`)

#### `parseText(text)`

Разбирает входной текст на массив слов.

```javascript
parseText('Hello world')
// ['Hello', 'world']
```

#### `getORPIndex(word)`

Вычисляет индекс оптимальной точки распознавания (ORP) для слова.

```javascript
getORPIndex('hello')
// 1 — вторая буква 'e'
```

#### `getActualORPIndex(word)`

Возвращает фактический индекс символа ORP с учётом начальных знаков препинания.

```javascript
getActualORPIndex('"hello')
// 2 — кавычка пропускается
```

#### `getWordDelay(word, wpm, pauseOnPunctuation, multiplier)`

Рассчитывает время отображения слова в зависимости от скорости чтения и настроек пауз.

```javascript
getWordDelay('hello', 300)
// 200 мс

getWordDelay('end.', 300, true, 2)
// 400 мс
```

#### `formatTimeRemaining(remainingWords, wpm)`

Форматирует оставшееся время чтения в формате `MM:SS`.

```javascript
formatTimeRemaining(300, 300)
// '1:00'
```

#### `splitWordForDisplay(word)`

Разделяет слово на части для отображения ORP.

```javascript
splitWordForDisplay('hello')

// {
//   before: 'h',
//   orp: 'e',
//   after: 'llo'
// }
```

#### `shouldPauseAtWord(wordIndex, pauseAfterWords)`

Проверяет, нужно ли сделать паузу после текущего слова.

```javascript
shouldPauseAtWord(10, 10)
// true

shouldPauseAtWord(5, 10)
// false
```

### Парсеры файлов (`src/lib/file-parsers.js`)

#### `parsePDF(file)`

Извлекает текст из PDF-файла.

#### `parseEPUB(file)`

Извлекает текст из EPUB-книги.

#### `parseFile(file)`

Автоматически определяет тип файла и выбирает соответствующий парсер.

#### `getSupportedExtensions()`

Возвращает список поддерживаемых расширений:

```text
.pdf,.epub
```

### Хранилище прогресса (`src/lib/progress-storage.js`)

#### `saveSession(session)`

Сохраняет текущую сессию чтения в `localStorage`.

```javascript
saveSession({
  text: 'Ваш текст...',
  currentWordIndex: 150,
  totalWords: 500,
  settings: {
    wordsPerMinute: 300
  }
})
// true
```

#### `loadSession()`

Загружает сохранённую сессию из `localStorage`.

```javascript
const session = loadSession()

// {
//   text: '...',
//   currentWordIndex: 150,
//   totalWords: 500,
//   settings: {...},
//   savedAt: 1234567890
// }
```

#### `hasSession()`

Проверяет наличие сохранённой сессии.

```javascript
hasSession()
// true или false
```

#### `clearSession()`

Удаляет сохранённую сессию из `localStorage`.

```javascript
clearSession()
// true
```

#### `getSessionSummary()`

Возвращает информацию о сессии без загрузки полного текста.

```javascript
getSessionSummary()

// {
//   currentWordIndex: 150,
//   totalWords: 500,
//   savedAt: 1234567890,
//   hasText: true
// }
```

#### `percentageToWordIndex(percentage, totalWords)`

Преобразует процент текста в индекс слова.

```javascript
percentageToWordIndex(50, 100)
// 50

percentageToWordIndex(25, 200)
// 50
```

#### `wordIndexToPercentage(wordIndex, totalWords)`

Преобразует индекс слова в процент текста.

```javascript
wordIndexToPercentage(50, 100)
// 50

wordIndexToPercentage(25, 50)
// 50
```
